# JK Taxi Brand Kit

Reference copies of the app's current brand assets and theme. The originals remain in their existing locations; update the originals first, then refresh these copies when needed.

## Logo

- `logos/jk_taxi_logo.png` is copied from `assets/images/jk_taxi_logo.png` and is the logo currently used by the app.

## Styles

- `styles/theme.ts` is copied from `src/constants/theme.ts` and contains the active app colors, spacing, typography sizes, border radii, font weights, and shadows.
